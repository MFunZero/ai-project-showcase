# AI 应用能力展示

面向对外介绍的静态项目宣传页，以智能客服 Demo 展示企业知识问答、业务工具调用、连续对话、售后流程与工单确认能力。

网页中的案例是本机验证结果摘录。页面的“实时 AI 体验”按钮打开独立的临时体验网址，可与真实模型对话；商品、订单与物流使用模拟数据。项目界面截图仅包含演示内容。

临时体验依赖演示方本机服务和通道保持运行，当前限制每个访客最多 20 次提交、本次网关最多 100 次提交、启动 24 小时后关闭访问。通道重新启动时需更新按钮地址；宣传页网址保持不变。

页面基于 MewHelp 课程项目的本地集成与验证成果制作。本仓库只包含介绍网页、展示素材和 PDF 手册，不包含客服服务源码、配置、数据库或 API 密钥。

由 GitHub Pages 发布。入口为 `index.html`，PDF 手册位于 `output/pdf/ai-application-brochure.pdf`。
